# storyboard/_template — 分镜骨架用法（剪辑台）

复制本目录到 `storyboard/<slug>/`，按顺序填：

1. **钩子 s00**（0–3s）
2. **章节板**（目录大字镜）
3. **各章口播+动效轨**（每镜对齐 `schemas/shot.schema.yaml`）
4. **结尾**
5. **验收镜**勾选 §验收

填完 S1 → 交给 `motion/<slug>/timeline.md` 做 S2（把每镜 `motion` 四段式落到时间线）。

`lens` 必须用「镜头 24 词表」专名（见 `methods/`）；禁止「好看一点」类空话。
