# 方法卡：Seedance 四段式 + 真人八维 + 稳定区

- **挂阶段**：S2 `motion` + 每镜 `safe_zone`
- **来源**：https://x.com/xiaohu/status/2084279939390755210 · 手册 https://best.xiaohu.ai/article/dreamina-seedance-25-guide/
- **@语法地基**：https://x.com/YangGuangAI/status/2020865177525305840

## 怎么用（本流水线）

写 `motion/<slug>/timeline.md` 与每镜 `motion.setup/action/hold/out` 时套四段式；有真人填八维；超出稳定区 = 抽卡。

### 四段式 Prompt

1. **素材说明**：编号 + 用途（`@图片1` 作首帧 / `@视频1` 参考运镜）
2. **一句话概括**：主体 / 地点 / 事件 / 风格 / 运镜
3. **具体情节**：正向动作 + 反向「不要…」
4. **全局补充**：全程锁定项 + 全局禁止项（字幕/BGM 等）

### 真人八维（有人脸必填）

年龄种族｜肤色质感（**强制保留毛孔**）｜五官≥3–4 点｜眼神｜发型发色｜服装质感｜体型情绪气质｜其他

### 稳定区（默认遵守）

| 项 | 上限 |
|---|---|
| 主体图 | 1–8 |
| 音视频主体 | 1–5 |
| 单段时长 | 5–10s |
| 编辑原片 | ≤20s |
| 参考图 | 1–5 |

### 每镜 `safe_zone` 备注示例

`图≤3；无双胞胎脸；保留毛孔；单段 6s`

## 禁止

- 裸写「好看一点」代替运镜/情节
- 超稳定区硬堆素材
